# Festa Junina - Os jogos

---

## How it was built?

- Python w/ Flask
- HTML & CSS
- Pure JS (so far)
- Image and sprites resources (ChatGPT)

# How to run?

```shell
sudo apt update
sudo apt install git -y
```

## w/ Venv
```shell
sudo apt install python3 -y
git clone https://github.com/LukazAllan/festajunina
cd festa_junina
python3 -m venv .
./bin/pip install flask
./bin/flask --app app.py run
```

## Globally
```shell
sudo apt install python3 python3-flask -y
git clone https://github.com/LukazAllan/festajunina
cd festa_junina
python3 -m flask --app app.py run
```
